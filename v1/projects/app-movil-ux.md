# App Móvil UX (UI / UX)

**MobileFlow** es una plataforma móvil diseñada para optimizar los flujos de interacción y retener al usuario final mediante animaciones fluidas y soporte offline.

![Experiencia Mobile First](https://images.unsplash.com/photo-1512941937669-90a1b58e7e9c?auto=format&fit=crop&w=1200&q=80)

## Detalles de Diseño e Interacción

*   **Animaciones a 60fps:** Implementación exclusiva con transform y opacity para evitar repintados innecesarios.
*   **Soporte Offline completo:** Estrategia de caché con Service Workers para garantizar navegación sin internet.
*   **Notificaciones personalizadas:** Integración segmentada con Firebase Cloud Messaging según el comportamiento.

---

## Tecnologías Utilizadas

- **Diseño:** Figma.
- **Frontend/Mobile:** HTML/CSS (CSS Grid), Progressive Web Apps (PWAs).
- **Backend/Notificaciones:** Firebase Cloud Messaging (FCM).
