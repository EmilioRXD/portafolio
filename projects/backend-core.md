# Backend Core (API REST)

**Backend Core** es una infraestructura de microservicios diseñada para soportar aplicaciones de alta concurrencia con una arquitectura de datos segura y escalable.

![Infraestructura en la Nube](https://images.unsplash.com/photo-1558494949-ef010cbdcc31?auto=format&fit=crop&w=1200&q=80)

## Características de Infraestructura

*   **Microservicios asíncronos:** Comunicación distribuida e independiente a través de Apache Kafka.
*   **Seguridad:** Autenticación OAuth 2.0 y tokens JWT con rotación automática.
*   **Protección y control:** Rate-limiting dinámico con Nginx y Redis.
*   **Documentación viva:** OpenAPI/Swagger generado directamente desde el código.

---

## Tecnologías Utilizadas

- **Servidor:** Node.js, Express.
- **Base de Datos:** PostgreSQL, Redis.
- **Mensajería:** Apache Kafka.
- **Contenedores:** Docker.
